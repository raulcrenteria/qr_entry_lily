# Check-in · Conferencia "Más allá de las aulas"

App para registrar la entrada de asistentes con QR o búsqueda por nombre.

- **Escanear QR:** la cámara lee el código de la persona → verde (adelante), ámbar (ya entró), rojo (no encontrado).
- **Buscar nombre:** para quien no trae su QR.
- Cada entrada queda anotada en la hoja de registros (columna **Entrada**: hora · puerta).

## Uso (staff)
1. Abrir el link de la app en el celular.
2. Escribir el PIN que te dio la coordinación y el nombre de tu puerta.
3. Escanear o buscar.

## Seguridad
- Esta página no contiene datos personales ni contraseñas.
- El PIN y los datos viven solo en Google, bajo la cuenta de la coordinación.
